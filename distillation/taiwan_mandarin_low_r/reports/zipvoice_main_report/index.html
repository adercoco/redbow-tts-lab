這份報告只看三個聲音：Qwen3 老師、ZipVoice 用老師聲音引導的學生、ZipVoice 原本女聲。

ZipVoice int8 作為學生 TTS

這還不是訓練出新權重的完整蒸餾，而是用老師聲音當 reference prompt，讓手機級 ZipVoice 生成台灣女生聲線。

學生原本

同一個學生模型的原廠女聲，不用老師聲音引導。可以看出 reference prompt 對聲線靠近有幫助。

模型大小同 ZipVoice pack，約 180.7-196.7MB

判斷

現階段以 ZipVoice int8 作為學生 TTS 發展是合理的：它已經能被老師聲音引導，速度和手機 ONNX 路線都比大模型務實。但它還不是「蒸餾完成」：目前是 zero-shot/reference-prompt student，不是訓練出單一台灣女生聲線的新權重。
